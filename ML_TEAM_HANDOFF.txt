  - Applied StandardScaler preprocessing (same as persisted scaler)
  - Computed IsolationForest.score_samples() (model output, range: -0.64 to -0.52)
  - Retrieved stored IF_score from unified file (range: 0.0 to 1.0)

  - Stored IF_score range: [0.000000, 1.000000]
  - Correlation (raw scores → stored): -0.036943 (essentially random)
  - Correlation (min-max inversion → stored): 0.036943 (essentially random)
  - Correlation (rank percentile → stored): undefined (different value ranges)

Interpretation:
  The stored IF_score values do NOT correlate with IsolationForest.score_samples()
  computed from the persisted model on the persisted features. This indicates:
  
  Hypothesis A: Different Feature Pipeline
    - The stored IF_score may have been computed from a different feature set
    - Feature engineering logic may have changed between stored scores and current artifacts
    - IMPACT: Cannot prove current feature matrix → stored score lineage
    
  Hypothesis B: Different Model Version
    - The stored IF_score may have come from a different IsolationForest training run
    - Model artifacts may have been updated without corresponding score re-computation
    - IMPACT: Cannot prove current model → stored score lineage
    
  Hypothesis C: Unknown Transformation
    - The stored IF_score may be a normalized/transformed version of the raw model output
    - Transformation logic (normalization, ranking, binning, etc.) is not documented
    - IMPACT: Cannot determine transformation from model output to stored score
    
  Conclusion: The current repository artifacts (feature matrix + scaler + model)
  do not constitute a complete, verifiable lineage for the stored Carrier risk scores.
